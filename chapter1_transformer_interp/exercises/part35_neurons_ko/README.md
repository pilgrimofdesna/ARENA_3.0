# 뉴런을 읽기 — 한국어 교재 (만드는 중)

**질문: 언어모델의 MLP 뉴런 하나는 해석의 단위가 될 수 있는가. 그렇다는 주장을 어떻게 검증하는가.**

목표는 동준이 정했다: "goodfire 의 뉴런을 제대로 이해하고, 그 주장의 신빙성을 검증할 수 있게 되고, 응용이 어느정도(claude의 도움 아래) 가능하게 되는 거" (2026-11-19).
대상 주장은 Goodfire의 논문 *Neurons as an Interpretable Basis*(Tigges et al., 2026-11-10)와 에세이 *Already Clean*이다.

ARENA에는 실제 LLM의 MLP 뉴런을 정면으로 다루는 장이 없어서, 여러 장(1.1 §2, 1.2 §3, 1.5.3 §2–3, 1.5.4 §1·2·5, 1.3.3 §1–2)에서 필요한 것을 골라 다시 짰다. **ARENA에 1.3.5는 없다.** 폴더 번호 35는 1.3.1 한국어판 다음에 오는 이 저장소만의 장이라는 표시다.

- 설계 의도: [`DESIGN/direction.md`](DESIGN/direction.md) (맨 위 "수정판"이 지금 유효한 설계)
- 결정과 가져온 자료의 기록: [`HISTORY.md`](HISTORY.md)

## 권

| 권 | 묻는 것 | 논문의 어느 부분 | 상태 |
|---|---|---|---|
| ① 뉴런 해부 | 뉴런 하나는 무엇을 읽고 무엇을 쓰나. 참/거짓을 가르는 뉴런은 특별한가 | 전제와 용어(활성, 극, 사분면) | 초판, 실행 출력 포함 (동준 검토 전) |
| ② 상대 이론 | 왜 다들 뉴런은 섞여 있다고 믿었나 (superposition) | 논문이 반박하는 것 | 초판, 실행 출력 포함 (동준 검토 전) |
| ③ 조금만 남겨도 되나 | 층마다 센 뉴런 몇 개만 남기면 손실이 얼마나 느나 | 주장 1 (top-320, 손실 +2.9%) | 초판, 실행 출력 포함 (동준 검토 전) |
| ④ 설명이 질 수 있나 | 글로 쓴 설명이 그 뉴런을 예측하나 | 주장 2, 3 | 계획 |
| ⑤ 반박과 응용 | 켜지는 조건이 곧 하는 일인가. 정직(역할극 거짓말)에 써 보기 | 논문이 하지 않은 것 | 계획 |

## 모델과 실행 환경

- 주 실험 모델: **Qwen3-0.6B-Base** (논문 모델 Qwen3.6-35B-A3B와 같은 계열, 같은 SwiGLU MLP, MoE는 아님). GPU 없이 CPU에서 돈다. 왜 바꿨는지는 `HISTORY.md`.
- Llama-3.1-8B-Instruct(1.3.1의 모델)로 같은 측정을 다시 하는 것은 GPU가 생기면 확인용으로 한다.
- 데이터와 probe 도구는 1.3.1 한국어판(`../part31_linear_probes_ko/`)의 것을 import해서 쓴다. 그 폴더가 같은 저장소에 있어야 한다.

```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu   # GPU가 있으면 그에 맞는 torch
pip install -r chapter1_transformer_interp/exercises/part35_neurons_ko/requirements.txt
# notebook을 ① → ⑤ 순서로 실행한다. 모델(약 1.2 GB)은 처음 실행할 때 내려받는다.
```

## 형식 (1.3.1 한국어판과 같음, 더한 것은 굵게)

- 학습 목표, 필수 경로, stop rule. 셀마다 `이번 셀의 질문 / 출력에서 볼 것 / 해석 범위`.
- **예측 칸**: 실행하기 전에 답을 적는 칸. 답은 바로 아래 출력에 있다. 출력을 먼저 보면 그 문제는 예측으로 세지 않는다.
- **[정의] [대수] [측정] [근사] 표시**: 식이 정의인지, 정확한 대수인지, 잰 값인지, 가정이나 근사인지를 줄마다 밝힌다.
- **구멍 장부**: 건너뛴 것과 그것이 다시 나오는 곳 (징검다리 공부법).
- 주장 장부: 권 끝마다 주장의 상태를 갱신하고 `results/*.json`에 숫자를 남긴다.
